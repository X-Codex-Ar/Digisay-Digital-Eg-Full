# Security requirements

The public contact endpoint accepts personal data but has no read endpoint. It validates server-side, applies rate limits, and persists through EF Core parameters. Protected CRM data requires active membership verified by the API, every route is scoped by the resulting request context, and EF global query filters constrain tenant-owned CRM queries. Keep SQL, Supabase server keys, SMTP, Redis, and OpenAI secrets out of frontend bundles. Firebase web configuration is public client configuration; Firebase Auth, Firestore, FCM, and Admin are not enabled. Revisit CSRF if cookie-based authentication is selected.
