# AI future roadmap

AI capabilities are out of the current implementation scope. No AI SDK, endpoint, or provider integration is included.

Possible future work, subject to product approval and privacy review: content analysis and categorization, moderation assistance, campaign insights, semantic search, content recommendations, report drafting, and operational assistance. Candidate providers include OpenAI, Anthropic, and Hugging Face. Evaluate a provider abstraction only if multiple providers are genuinely required. Any future implementation needs explicit model selection, cost/token budgets, data minimization and retention controls, tenant isolation, prompt/output security, rate limits, background processing for long jobs, structured observability without sensitive prompts, human review for consequential actions, and provider failure handling.
