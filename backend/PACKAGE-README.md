# DigiSay .NET libraries

These packages contain the reusable .NET 10 libraries that power the DigiSay platform:

- **DigiSay.Domain** provides core business entities and domain rules.
- **DigiSay.Application** provides application use cases and contracts.
- **DigiSay.Infrastructure** provides database, identity, storage, AI, and integration adapters.

The web API is deployed as a container image and is not published as a NuGet library. The packages target .NET 10 and are released together from this repository.

The GitHub Packages NuGet feed is `https://nuget.pkg.github.com/X-Codex-Ar/index.json`.
